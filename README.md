# Simulador de Preço — Plataforma de controle (Mercado Livre)

Plataforma simples para controlar a revenda no Mercado Livre: simulador de preço,
triagem de compra, compras, vendas, estoque automático e painel.

- **Front-end:** site estático (HTML + CSS + JavaScript com módulos ES), sem build.
- **Back-end (a partir da Etapa 2):** Supabase (Postgres + Auth).
- **Publicação:** GitHub Pages.

O simulador é público. Todo o resto exige login (só quem for convidado).
